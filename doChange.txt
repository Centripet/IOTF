3. InfluxDB配置
----------------

3.1 Bucket配置
---------------
已配置：bucket = "energy"

3.2 Measurement配置
-------------------
使用的measurement名称：
- device_energy_raw - 原始设备能耗数据

3.3 数据保留策略(Retention Policy)
-----------------------------------
建议配置：
- 原始数据保留：30天
- 聚合数据保留：1年

3.4 需要创建的实时聚合任务(需手动创建)
---------------------------------------
如果需要实时聚合功能，需在InfluxDB中创建以下任务：

// 每分钟聚合
option task = {name: "energy_minute_agg", every: 1m}
from(bucket: "energy")
  |> range(start: -1h)
  |> filter(fn: (r) => r._measurement == "device_energy_raw")
  |> aggregateWindow(every: 1m, fn: mean)
  |> yield(name: "mean")

// 每小时聚合
option task = {name: "energy_hour_agg", every: 1h}
from(bucket: "energy")
  |> range(start: -24h)
  |> filter(fn: (r) => r._measurement == "device_energy_raw")
  |> aggregateWindow(every: 1h, fn: mean)
  |> yield(name: "mean")

// 每日聚合（用于高能耗告警检测）
option task = {name: "energy_daily_agg", every: 1d}
from(bucket: "energy")
  |> range(start: -30d)
  |> filter(fn: (r) => r._measurement == "device_energy_raw")
  |> aggregateWindow(every: 1d, fn: sum)
  |> yield(name: "sum")

- clientId: collect-analyze-service

4.2 需要订阅的主题
-------------------
建议订阅以下主题：

- energy/device/+/status   - 设备状态变更

-------------
支持两种消息格式：

格式1：JSON格式（推荐）
{
  "deviceId": "DEV001",
  "deviceUUID": "device-uuid-xxx",
  "timestamp": "2024-01-01T12:00:00",
  "current": 2.5,
  "voltage": 220.0,
  "power": 550.0,
  "energy": 9.17,
  "isComplete": true,
  "deviceType": "AIRCON",
  "location": "客厅",
  "isOn": true,
  "isFault": false,
  "commType": "WIFI",
  "totalEnergy": 1250.5
}

格式2：简单格式（兼容C代码）
ID:DEV001,TIME:1704067200,CURR:2.5,VOLT:220.0,POWER:550.0,ENERGY:9.17

-----------------

  filter:
    enabled: true       # 启用数据滤波
    new-weight: 0.7     # 新值权重
    old-weight: 0.3     # 旧值权重
  cleaning:
    voltage-min: 200    # 电压最小值(V)
    voltage-max: 240    # 电压最大值(V)
    current-max: 30     # 电流最大值(A)
    power-max: 5000     # 功率最大值(W)

7. 告警检测逻辑说明
--------------------

7.1 过载告警(OVERLOAD)
----------------------
触发条件：设备开机状态 && 功率 > 过载阈值(默认2000W)
级别：CRITICAL

7.2 高能耗告警(HIGH_ENERGY)
---------------------------
触发条件：设备当日累计能耗 > 高能耗阈值(默认500Wh)
级别：WARNING

7.3 漏电告警(ELECTRIC_LEAK)
---------------------------
触发条件：电流 > 电流阈值(默认10A) && 功率 < 电流 * 电压 * 0.5
级别：CRITICAL

7.4 设备故障告警(DEVICE_FAULT)
-----------------------------
触发条件：设备上报故障状态(isFault=true)
级别：WARNING
